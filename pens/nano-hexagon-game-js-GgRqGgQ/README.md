# NANO HEXAGON 🕹️ (Game, JS)

> 18 loves · 2 comments · 896 views

🔥 I recommend to use https://codepen.io/konstantindenerz/full/GgRqGgQ instead of preview window.


Nano Hexagon is a minimalist mini-game inspired by the Micro Hexagon (C64, https://rgcddev.itch.io/micro-hexagon) where players dodge dynamically shifting obstacles in a fast-paced arcade setting. The background track is provided by nickpanek620 (https://pixabay.com/es/music/video-juegos-chiptune-medium-boss-218095/).

⚠️ This video game features extensive use of stroboscopic effects and should not be played by individuals who are sensitive to intense flashing lights. If you experience dizziness, blurred vision, eye or muscle twitches, loss of consciousness, disorientation, any involuntary movement or convulsion whilst playing NANO HEXAGON, discontinue use IMMEDIATELY and consult your doctor.
