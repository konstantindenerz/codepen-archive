# Scroll Indicator (Top / Bottom) CSS

> 2 loves · 0 comments · 181 views

The top and bottom are faded out using masking so that the user can see that scrolling in that direction is possible at all. This is implemented using animation-timeline, scroll() and mask.

Works in Chromium-based browsers.
